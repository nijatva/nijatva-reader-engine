# Performance

No number appears in this repository without the device, Android version, build type,
command and method that produced it. There are no numbers yet, because M0 ships no
renderer.

When measurements start (M6 onwards), they are recorded here as: device · Android version
· build type · command · p50/p90/p95/p99 · peak heap, and compared against the budget in
`ENGINE-SPEC.md` §8 rather than against a flattering previous run.
